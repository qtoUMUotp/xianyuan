# 仙缘匹配测试 v1.1 · Xianyuan Protocol

> 测试你与哪种仙家有缘 —— 一个纯前端的东北民俗风趣味测试。

零依赖、零构建、无后端。双击 `index.html` 就能玩。

---

## 它是什么

一个 16 道选择题的趣味测试，算出你与 36 路"仙家"里哪一路最合拍。

"仙家"取自东北民间信仰中的**动物出马仙**传统（胡、黄、白、柳、灰五大家仙等），
v1.1 起也纳入了红松、人参、白桦等**草木山珍**。
每位仙家都对应一种**真实存在的动植物**，结果页会给出该物种的学名、在东北的分布、
习性、冷知识和保护现状。

纯娱乐个人编造，不算命，不占卜，不涉及任何宗教信仰引导。
注意：本项目基本由AI完成，仅出于个人学习、娱乐目的使用，著作权属于人类。

## 功能

- **16 道情境题**，逐题作答，可前进后退
- **加权算分**：每个选项给 3 位仙家分别加 3 / 2 / 1 分
- **归一化排序**：用 `raw / max^0.72` 排名，避免冷门仙家永远抽不到（见下方算法说明）
- **结果页**：牌位卡 + 契合度环、签文、宜忌、次缘、TOP5 缘分图谱
- **动植物科普**：学名 / 在东北 / 习性 / 冷知识 / 保护现状 / 民俗侧写
- **东北生态 4 卡**：红松林、三江平原候鸟通道、黑龙江冷水鱼、公众能做的环保小事
- **仙家名录**：36 位全览，点开看详情
- **分享**：复制文案 / 复制链接（链接带 `#r=主缘&s=次缘&f=契合度`，打开即还原结果）
- **赛博视觉**：透视网格、扫描线、噪点、故障标题、雪花粒子、切角卡片
- **无障碍 / 性能**：`prefers-reduced-motion` 自动降级动画，键盘 1/2/3/4 可选项
- **隐私**：答题数据只在本地内存，不上传、不落库

## 算法说明

朴素做法是按原始总分排名，但各仙家**出现在题目里的次数差异很大**
（蛛仙 10 题，哲罗鱼、水獭等只有 3~4 题），直接比总分会让冷门仙家几乎不可能中签。

完全改成"得分率"（`raw / max`）又矫枉过正，热门仙家反而被压下去。

所以引入指数 α：

```
value = raw / max^α
```

用蒙特卡洛模拟（20 万次随机答题）扫描 α ∈ [0, 1]，取分布标准差最小的 **α = 0.72**。
最终实测（v1.1 · 36 位）：

| 指标 | α = 0（原始分） | α = 1（完全归一化） | **α = 0.72（采用）** |
| --- | --- | --- | --- |
| 最低出现率 | 0.00% | 0.64% | **0.96%** |
| 最高出现率 | 22%+ | 7.88% | **4.24%** |
| 极差比 | ∞ | 12.25 | **4.40** |
| 死结果数 | 多 | 0 | **0** |

契合度数值 = `60 + 完成度 × 28 + 领先度 × 10`，既有区分度也不会顶死在 99%。

## 二次开发

- **加一位仙家**：在 `data.js` 的 `spirits` 数组里加一项，然后在若干题目的
  `score` 里引用它的 `id`。建议至少覆盖 3~4 道题，否则出现率会偏低。
- **加 / 改题目**：改 `questions` 数组。每道题固定 4 个选项，
  每个选项的 `score` 给 3 位仙家打分，分值取 1 / 2 / 3。
- **改配色**：改 `data.js` 里仙家的 `hue`，或改 `style.css` 顶部 `:root` 的四个主色。
- **改文案**：生态科普在 `ecoNotes`，免责条款在 `disclaimer`。

改完在根目录跑一次自检：

```bash
node verify.js
```

它会检查 id 是否唯一、题目引用的仙家是否存在、选项数与权重是否合规、字段是否齐全、
哪些仙家出现题数偏少，并跑 20 万次随机答题给出出现率分布和死结果检查。
